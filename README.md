A GTA 6 meme for the make.fun bounty "Post a GTA 6 meme on X": a make.fun air boarding pass, LOS SANTOS → LEONIDA, flight GTA VI, departs 2013, arrives 2026, stamped DELAYED 13 YEARS. The meme (`meme.png`, 1200×1200) is drawn by `make_meme.py` (Python + Pillow) with make.fun's ghost mascot as the airline logo and stub art. The entry is the X post named in `POST.json`; `main.ts` copies `POST.json` to the output directory for the gate.

## Run it

```sh
python3 make_meme.py
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
